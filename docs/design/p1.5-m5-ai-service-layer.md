## CR §4.3 contract — three methods, any pipeline stage

> The layer must support: local or remote inference; graceful degradation / CPU fallback; clear status and error reporting to the UI; optional free-path engines alongside higher-quality paid/accelerated engines.

```
AIService
├── analyse(image, stage)         -> AnalysisResult   (read-only, fast)
├── suggestParams(image, stage, dataType) -> ParamProposal   (used by Automagic Expert)
└── execute(image, stage, params) -> ProcessedImage    (the actual transformation)
```

## Proposed Rust surface (M1.5.5 T1 — interface only)

```rust
// crates/astroforge-ai/src/service.rs

use astroforge_core::image::F32Image;
use crate::models::DeterminismRecord;
use crate::hardware::QualityTier;
use serde::{Deserialize, Serialize};

/// A stage in the 10-stage process train.
/// Mirrors CR §4.1 canonical stages + the MVP stages from spec §7.
#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq, Hash)]
#[serde(rename_all = "snake_case")]
pub enum PipelineStage {
    CompressionCleanup,    // 0.5
    Ingest,                // 1
    QualityFilter,         // 2
    Debayer,               // 3
    Calibration,           // 4
    CosmeticCorrection,    // 5
    Registration,          // 6
    PlateSolve,            // 6.5
    Stacking,              // 7
    NarrowbandCompose,     // 7.5
    BackgroundExtraction,  // 8
    ColorCalibration,      // 9
    NarrowbandColor,       // 9.5
    CropAndRotate,         // 10
    Stretching,            // 11
    Deconvolution,         // 12
    NoiseReduction,        // 13
    StarSegEnhancement,    // 14
    AiSuperResolution,     // 15
    FinalDetailEnhancement,// 16
    Export,                // 17
}

/// Detected data-type context for the AI's parameter suggestions.
/// Per CR §4.4 "data-type declaration" and §5.4 "What did you shoot?"
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DataType {
    pub camera: CameraKind,        // OscMono, OscDualBand, MonoNarrowband, MonoLrgb
    pub filter: FilterKind,        // Broadband, Ha, Oiii, Sii, L, R, G, B
    pub bit_depth: u8,
    pub is_linear: bool,
    pub exposure_seconds: f32,
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum CameraKind { OscMono, OscDualBand, MonoNarrowband, MonoLrgb }

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum FilterKind { Broadband, Ha, Oiii, Sii, L, R, G, B, Other }

/// Result of a non-mutating analysis pass.
/// Returned by `AIService::analyse`; used to drive UI hints and quality metrics.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AnalysisResult {
    pub stage: PipelineStage,
    /// Free-form metrics, e.g. {"snr": 24.3, "star_count": 142, "fwhm_median": 2.1}
    pub metrics: serde_json::Map<String, serde_json::Value>,
    /// Short, human-readable findings shown in the UI ("12 frames have cloud score > 0.7").
    pub findings: Vec<String>,
    /// 0..=1 confidence in the analysis itself (model degradation, low SNR, etc.).
    pub confidence: f32,
    /// Determinism record so the analysis is reproducible.
    pub determinism: DeterminismRecord,
}

/// Proposed parameter set the AI can apply.
/// Used by Automagic Expert: the user accepts / rejects / refines in dialogs.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ParamProposal {
    pub stage: PipelineStage,
    pub params: serde_json::Value,         // stage-specific parameters
    pub rationale: String,                 // one-line "why" shown in the UI
    pub expected_improvement: f32,         // 0..=1 subjective; drives UI accent
    pub confidence: f32,                   // 0..=1
    pub determinism: DeterminismRecord,
}

/// Result of a mutating execute pass.
#[derive(Debug, Clone)]
pub struct ProcessedImage {
    pub image: F32Image,
    pub determinism: DeterminismRecord,
}

/// Identifier for which engine handled a call.
/// Surfaces in the UI as "Handled by: local SwinIR (Balanced tier)" per CR §5 NFR.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum EngineKind {
    Local { model: String, tier: QualityTier },
    Remote { endpoint: String, model: String },
    CpuFallback { reason: String },
}

/// Free-path vs accelerated-path selection per CR §4.3 + §5 NFR.
/// UI shows the choice with transparent messaging; never silent.
#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum ServicePath {
    Free,         // CPU / local quantized, no cost, lower quality
    Accelerated,  // GPU / remote / paid model, higher quality
}

/// The unified interface every pipeline stage calls.
///
/// CR §4.3: "Design the AI service interface so any stage can request
/// analysis, parameter suggestion, or full execution, then receive a
/// structured proposal that Automagic Expert can surface."
pub trait AIService: Send + Sync {
    fn analyse(
        &self,
        image: &F32Image,
        stage: PipelineStage,
    ) -> AnalysisResult;

    fn suggest_params(
        &self,
        image: &F32Image,
        stage: PipelineStage,
        data_type: &DataType,
    ) -> ParamProposal;

    fn execute(
        &self,
        image: &F32Image,
        stage: PipelineStage,
        params: &serde_json::Value,
    ) -> ProcessedImage;

    /// Which engine would handle `execute` for this stage right now?
    /// Used by the UI to surface "Handled by: local SwinIR (Balanced)" before commit.
    fn engine_for(&self, stage: PipelineStage) -> EngineKind;

    /// Free vs accelerated path selection — explicit, never silent.
    fn path_for(&self, stage: PipelineStage) -> ServicePath;
}
```

## Decisions baked into the interface (review items)

1. **One trait, three methods.** No async. The CR doesn't require async — the
   long-running calls report progress via the `Progress` channel (separate type,
   T4). Async can be added later behind a wrapper if needed without breaking
   the trait shape.
2. **`PipelineStage` enum covers MVP (spec §7) + CR stages (CR §4.1)**, mapped 1:1
   to the 20 stages including the `0.5` and `7.5` sub-stages. New stages add new
   enum variants (non-exhaustive in v2).
3. **`DataType` carries camera + filter + bit-depth + linear/stretched.** The
   CR §4.4 specifies data-type awareness; M1.5.8 (#184–#187) owns the *detection*
   logic; here we just consume it.
4. **`AnalysisResult.metrics` is `serde_json::Map`**, not a fixed struct, so
   each stage can report its own stats (SNR, FWHM, star count, cloud score, etc.)
   without trait churn.
5. **`ParamProposal` is a generic `serde_json::Value` for `params`.** Stage-specific
   parameter structs live in each stage module and serialize through; the service
   stays parameter-shape-agnostic.
6. **`EngineKind` + `ServicePath` are surfaced to the UI**, not just used internally.
   CR §5 NFR requires transparent messaging; both fields are `Serialize` so the
   Tauri command layer can pass them to Svelte directly.
7. **No I/O, no network in this trait.** Concrete impls (T2 — dispatch) wrap
   local models / remote HTTP / CPU fallback and decide which `EngineKind` to
   report. The trait stays pure, testable, and free of `tokio`.
8. **Determinism is recorded at every return** — matches existing `models.rs`
   `DeterminismRecord` contract (spec §10.6) and gives Phase 3 recipe export
   (`P3-M2-T1` etc.) a stable fingerprint to embed.
